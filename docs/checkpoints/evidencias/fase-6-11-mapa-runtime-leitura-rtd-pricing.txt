FASE 6.11 — Evidência: mapa runtime de leitura RTD no pricing

Branch:
fase-6-11-retomada-funcional-pos-restauracao-documental

Objetivo:
Documentar, sem alteração de código, o caminho real de leitura RTD usado pelo fluxo runtime de pricing.

Conclusão:
O fluxo runtime principal de pricing não lê rtd_option_quotes.

Fluxo runtime confirmado:
PricingExecutionAppService
  -> CanonicalPricingFacade
      -> structures
      -> MarketSnapshotRepository
      -> MarketSnapshotSelector
      -> PricingExecutionService
      -> PricingExecutionPersistenceService

Banco padrão:
dados/app.db

Entrada produtiva:
services/pricing_execution_app_service.py

Evidência:
PricingExecutionAppService instancia CanonicalPricingFacade com db_path padrão dados/app.db.

CanonicalPricingFacade:
- resolve alias_legacy_aba e underlying_asset na tabela structures;
- chama MarketSnapshotSelector.select(aba=alias_legacy_aba);
- converte as legs selecionadas para pricing_payload;
- executa engine;
- persiste execução.

Tabelas lidas pelo MarketSnapshotRepository:
- manual_analise_robo_legs
- rtd_analise_robo_legs
- rtd_analise_robo

Política de seleção:
MarketSnapshotSelector aplica manual > RTD por ativo:
- se houver leg manual para o ativo, usa manual;
- caso contrário, usa RTD;
- as consultas vêm ordenadas por timestamp DESC;
- a primeira ocorrência por ativo tende a representar a leitura mais recente.

Observação sobre spot:
MarketSnapshotRepository possui get_rtd_summary() lendo rtd_analise_robo.
Porém, no caminho direto da CanonicalPricingFacade, a seleção é feita por MarketSnapshotSelector.select(),
cujo SnapshotSelectionResult não carrega spot.
Assim, o spot_price é resolvido em _snapshot_result_to_payload por:
1. atributos spot/spot_price/underlying_price/last_price em selection_result, se existirem;
2. fallback _lookup_spot_price(db_path, underlying_asset), que varre tabelas do app.db buscando colunas compatíveis de símbolo e preço.

Situação de rtd_option_quotes:
- repositories/rtd_option_quotes_repository.py existe;
- services/structure_leg_rtd_enrichment_service.py existe;
- ambos aparecem cobertos por testes;
- não foi encontrada instanciação produtiva de RtdOptionQuotesRepository fora dos testes;
- não foi encontrada instanciação produtiva de StructureLegRtdEnrichmentService fora dos testes;
- portanto, rtd_option_quotes não participa do fluxo runtime principal de pricing nesta branch.
