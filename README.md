# Robô de Opções v2.0.0

Sistema de análise e simulação de operações com opções financeiras.

## Funcionalidades
- Interface gráfica para análise de payoff
- Pipeline de dados automatizado
- Relatórios e análises detalhadas

## Estrutura
- `dados/`: Dados de entrada e processados
- `UI/`: Interface gráfica
- `services/`: Lógica de negócio
- `scripts/`: Scripts auxiliares
- `docs/`: Documentação

## Instalação
1. Clone o repositório
2. Instale as dependências: `pip install -r requirements.txt`
3. Execute: `python UI/main_window.py`
